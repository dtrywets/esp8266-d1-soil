Bodenfeuchte — Web Flash

Firmware per USB flashen · ESP8266 D1 Mini oder ESP32-C3 (Auto-Erkennung) · GitHub

Firmware installieren

Verbindet per Web Serial (Chrome/Edge), erkennt den Chip automatisch und wählt die passenden Firmware-Images aus dem Manifest. Nach dem Flash erscheint direkt die WLAN-Einrichtung (Improv).

ESP8266 (D1 Mini) ESP32-C3 Improv Wi-Fi

WLAN verbinden

Nur WLAN einrichten — ohne erneutes Flashen. USB anschließen, Netzwerk wählen, Zugangsdaten senden. Die Firmware speichert SSID/Passwort und startet neu. Danach öffnet der Browser das Dashboard (http://<IP>/).

MQTT und Kalibrierung weiterhin im Geräte-Dashboard — WLAN reicht hier für den Einstieg.

Voraussetzungen

  • Browser: Google Chrome oder Microsoft Edge (Web Serial)
  • USB-Datenkabel zum Board (nicht nur Ladekabel)
  • Sensor-Versorgung: 3,3 V — nie 5 V am ADC
  • Bei Problemen: Boot-Taste gedrückt halten, dann „Flashen“ starten
Beim ersten Flash wird der Flash-Speicher gelöscht (empfohlen). WLAN direkt nach dem Flash oder über „WLAN einrichten“ setzen. MQTT optional im Dashboard oder per config.h vor dem Build.

Alternativen

  • PlatformIO USB: pio run -e d1_mini -t upload / pio run -e esp32c3 -t upload
  • OTA (nur wenn Firmware läuft): pio run -e d1_mini_ota -t upload
  • Laufendes Gerät: Dashboard Tab „Firmware“ (HTTP-Upload)

Hosting

Diese Seite wird aus dem GitHub-Repository per GitHub Pages veröffentlicht (dtrywets.github.io/esp8266-d1-soil). Bei jedem Push auf main baut die Action die Firmware und aktualisiert die .bin-Dateien automatisch.

Lokal testen: ./scripts/build-webflash.sh und cd webflash && python -m http.server 8765
